# Native Capture App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A SwiftUI iPhone + iPad app in `timing_app/` with feature parity with the capture PWA (`frontend/capture/`), talking to the unchanged hub `/sync/v1` API.

**Architecture:** A UI-free `Core/` ports each TS module (`hash`, `log`, `db`, `clock`, `location`, `rows`, `api`, `sync`) with the same rules, tested with Swift Testing against the same cases as the TS tests and the hub's shared checksum vector. A SQLite store behind one actor gives durable, serial appends. `UI/` is SwiftUI over an `@Observable` app model.

**Tech Stack:** Swift (Swift 5 language mode, like LiftLog), SwiftUI, iOS 17+, system `sqlite3`, CryptoKit, URLSession, VisionKit, Swift Testing, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-11-26-native-capture-app-design.md`

## Global Constraints

- iOS deployment target `17.0`; `TARGETED_DEVICE_FAMILY: "1,2"`; all four orientations on iPad, portrait + both landscapes on iPhone.
- Bundle id `com.ronmiles.timingcapture`; display name `Timing Capture`; `DEVELOPMENT_TEAM: Q3KYUZGC72`; `SWIFT_VERSION: "5.0"`.
- No third-party dependencies.
- The `.xcodeproj` is generated by `xcodegen` and git-ignored (`timing_app/*.xcodeproj`).
- No hub changes. If a task seems to need one, stop and ask.
- Checksum: SHA-256 hex of canonical JSON — keys sorted (byte order), no whitespace, null/absent fields omitted, `hash` key excluded; genesis = SHA-256 hex of the device id string. Strings escaped like `JSON.stringify`: `\"`, `\\`, `\b \f \n \r \t`, other code points < 0x20 as `\u00xx` (lowercase hex); `/` and non-ASCII written raw. Integers written as plain decimal.
- Intervals (from `sync.ts`): tick 1 s; roster 60 s; clock 60 s (5 samples, keep fastest RTT); push every 5 s while pending, batches of 500; status 10 s; backoff 1 s doubling to 30 s; request timeout 10 s.
- Bib entry: digits only, at most 6; Enter with nothing typed records a no-bib crossing.
- The log is never deleted: unpair is refused while anything is unsent; re-pair archives the old log.
- User-facing copy is copied from `frontend/capture/src/App.tsx` / `SyncPill.tsx` verbatim, except "page"/"browser"/"home screen" wording that no longer applies (the storage warnings are dropped entirely).
- Test command (referred to below as **RUN TESTS**), from `timing_app/`:
  `xcodegen -q && xcodebuild test -project TimingCapture.xcodeproj -scheme TimingCapture -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -quiet`
  Narrow with `-only-testing:TimingCaptureTests/<SuiteType>`.

## Review Focus

1. **A relaunch mid-event** (app killed, phone rebooted): every confirmed tap is still there and the next tap continues the chain (seq + prev_hash) — pinned in Task 2 (`reopenContinuesChain`).
2. **Hub addresses as people type or paste them** (`192.168.1.5`, `hub.local:3443`, `https://hub.local:3443/capture-app/?pair=k7q-4mx`, trailing spaces, `http://` in a release build) — pinned in Task 4 (`HubAddressTests`).
3. **Tapping before the clock has ever synced:** the capture is recorded with no `clock_offset_ms` key, and hashes like the hub expects — pinned in Task 2 (`captureWithoutOffsetOmitsKey`).
4. **Bibs with leading zeros** (`"007"`) stay strings end to end — pinned in Task 1 (`leadingZeroBibStaysString`).
5. **Backgrounding and foregrounding repeatedly** never runs two sync loops at once — pinned in Task 5 (`startTwiceRunsOneLoop`).

### Task 2: Store and log

**Files:**
- Create: `Core/Entry.swift`, `Core/Store.swift`
- Test: `TimingCaptureTests/StoreTests.swift`

**Interfaces:**
- Consumes: `JSONValue`, `DeviceHash` (Task 1).
- Produces:
  - `struct Pairing: Codable, Equatable, Sendable { var hubURL: URL; var deviceId: String; var credential: String; var eventId: String; var name: String }`
  - `struct Entry: Codable, Equatable, Sendable, Identifiable { enum Kind: String, Codable { case capture, bib_assignment, capture_void, location }; var id: String; var kind: Kind; var device_seq: Int; var prev_hash: String; var hash: String; var captured_at_ms: Int?; var clock_offset_ms: Int?; var bib: String?; var capture_id: String?; var checkpoint_id: String?; var fields: [String: JSONValue] }` — `fields` is all non-nil properties incl. `hash`; encoding omits nil keys (snake_case keys as listed, they go to the hub as-is).
  - `struct ArchivedLog: Codable, Sendable { var pairing: Pairing?; var entries: [Entry]; var archivedAtMs: Int }`
  - `actor CaptureStore`:
    - `init(path: URL) throws` — opens/creates SQLite, `PRAGMA journal_mode=WAL; PRAGMA synchronous=FULL;`, creates tables `pairing(k TEXT PRIMARY KEY, v BLOB)`, `entries(device_seq INTEGER PRIMARY KEY, v BLOB NOT NULL)`, `state(k TEXT PRIMARY KEY, v BLOB)`, `archive(id INTEGER PRIMARY KEY AUTOINCREMENT, v BLOB)`; values are JSON.
    - `static func defaultURL() -> URL` (Application Support/`capture.sqlite3`)
    - `func pairing() throws -> Pairing?`, `func clearPairing() throws`
    - `func get<T: Decodable>(_ key: String, as: T.Type) throws -> T?`, `func put<T: Encodable>(_ key: String, _ value: T?) throws` (nil deletes)
    - `func appendCapture(atMs: Double, offsetMs: Int?, bib: String, checkpointId: String?) throws -> Entry` (rounds atMs; empty/blank bib → no key)
    - `func appendLocation(checkpointId: String?, atMs: Double, offsetMs: Int?) throws -> Entry`
    - `func appendBibAssignment(captureId: String, bib: String) throws -> Entry`, `func appendVoid(captureId: String) throws -> Entry`
    - `func allEntries() throws -> [Entry]`, `func unsent(after ackSeq: Int, limit: Int) throws -> [Entry]`, `func lastSeq() throws -> Int`
    - `func startNewPairing(_ next: Pairing) throws` (one transaction: archive old pairing+entries if any, clear entries and state, store next), `func archives() throws -> [ArchivedLog]`
  - `func canUnpair(lastSeq: Int, ackSeq: Int) -> Bool`

Appends are synchronous inside the actor (no `await` between reading the last entry and inserting), so the actor serialises them. Use `INSERT` (never `INSERT OR REPLACE`). Throw `"This phone isn't paired"` (a `CaptureError.notPaired` whose description is that text) when appending unpaired.

### Task 7: App shell — pair (typed) and capture with the keypad

The first runnable slice: pair, tap, see sync status.

**Files:**
- Create: `App/AppModel.swift`, `UI/PairView.swift`, `UI/CaptureView.swift`, `UI/Keypad.swift`, `UI/SyncPill.swift`; modify `App/TimingCaptureApp.swift`.

**Interfaces:**
- Consumes: everything in Core.
- Produces:
  - `@MainActor @Observable final class AppModel { init(store: CaptureStore); var pairing: Pairing?; var sync: Sync?; var entries: [Entry]; var bib: String; var flash: Bool; var error: String?; var tapClock: TapClock; func pair(address: String, code: String, name: String) async /* sets error on failure */; func tap(atMs: Double) async; func typeDigit(_ d: String); func backspace(); func reload() async; func scenePhaseChanged(_ phase: ScenePhase) }`
  - `struct Keypad: View { init(enterLabel: String = "Enter", compact: Bool = false, onDigit: (String) -> Void, onBack: () -> Void, onEnter: ((Double) -> Void)?) }` — `onEnter` receives the touch-down time from the parent's `TapClock`.

Behaviour:
- `pair`: `HubAddress.parse` (nil → error "Enter the hub address shown on the console"); code from the field wins over one in a pasted URL; `HTTPHubAPI(base:auth: { nil }).pair`; then `store.startNewPairing(Pairing(hubURL:…, name: name.trimmed.isEmpty ? "Phone" : name))`; start sync.
- `tap(atMs:)`: `store.appendCapture(atMs:, offsetMs: sync.state.offsetMs, bib:, checkpointId: sync.state.location?.checkpointId)`; only after it returns: clear bib, `flash` for 150 ms, `UINotificationFeedbackGenerator().notificationOccurred(.success)`, reload, `sync.kick()`. On throw: `error = "Not recorded: <message>"`, `.error` haptic.
- `typeDigit` caps at 6 digits.
